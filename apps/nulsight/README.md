# Nulsight

`Nulsight` is now tracked inside the portfolio monorepo.

- runtime root: `apps/nulsight`
- public client: `apps/nulsight/public`
- app docs: `apps/nulsight/docs`
- shared neutral theme source: `themes/theme.oklch.css`
- local game palette source: `apps/nulsight/public/palette.oklch.css`
- audio assets: `apps/nulsight/public/audio/bgm`, `apps/nulsight/public/audio/sfx`
- audio manifest/runtime seed: `apps/nulsight/src/client/audio`

This app still keeps its static HTML + JS structure, but it now shares the portfolio theme baseline and build rules.
